# AOJ 100 题 C 程序数据集自动采集与验证实验（2026-08-20）

## 实验目标

从 Aizu Online Judge（AOJ）公开数据中构建 100 个 C 程序问题的数据集。每题保留 10 份不同的公开 AC 代码，重点筛选含数组或指针操作且适合进一步剥离竞赛 I/O 外壳后输入 Eppather 的程序。

## 自动化配置

| 配置项 | 数值 |
|---|---:|
| AOJ 公开题目目录 | 3438 题 |
| 并行采集分片 | 20 |
| 每分片目标 | 7 题 |
| 每题公开 AC 代码 | 10 份 |
| 每题最多下载官方测试 | 20 组 |
| 每种语言提交扫描上限 | 200 |
| 请求间隔 | 0.75 秒/分片 |
| 单程序运行超时 | 3 秒 |
| 编译标准 | C11，`-O0` |

筛选拒绝 struct/union/enum、typedef、宏、VLA、动态内存、goto/switch/do、浮点、可变参数、函数指针、C++ 语法和未知外部调用。每一份最终代码必须满足：公开 AC、源码哈希去重、C11 编译成功、所有已下载官方测试回放通过，并且包含数组或指针特征。

## 结果解释与边界

本次 100% 表示数据获取、C11 编译和 AOJ 官方测试回放均通过，证明 1000 份代码保持原题功能正确性。兼容性筛选是 Eppather 前置语法筛选；完整竞赛程序仍含 `main` 和标准输入输出外壳，不能把本次结果解释为 1000 份未处理源码已经直接完成 Eppather DFS2/DP 路径分析。后续路径实验应先剥离 I/O 外壳并确定函数入口，再分别统计原生 slice、近似 slice、DFS2/DP 成功率及 MEMS 一致率。
