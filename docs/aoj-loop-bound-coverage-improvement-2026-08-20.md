# AOJ覆盖率改进：循环上界与可行路径修复

## 问题与修复

旧实验使用 `--maxloop 2`。Eppather到达展开上界后会结束枚举，但固定循环（例如 `for (i=0; i<10; i++)`）的原始守卫在第2次后仍为真；若路径末尾又要求原守卫为假，约束会矛盾，导致整条路径被判不可行。

本轮在规范化模型的每个词法循环中加入独立、进入时重置的计数器。循环退出条件变为“原守卫为假或计数器达到上界”，因此有界退出不再强迫原守卫变假。同时把首选上界提高到5、路径上限从80提高到200。为控制路径爆炸，单题按5、3、2自适应回退，并记录实际采用的上界。

## 结论与边界

循环退出语义修复解决了“达到展开上界却要求原循环条件为假”的伪不可行问题。上界5显著增加候选路径并提高覆盖率，自适应回退避免统一高上界导致原本可分析题超时丢失。剩余低覆盖主要集中在复杂输入映射、辅助函数、数组求解能力和路径爆炸，不应继续仅靠无限提高 `maxloop` 解决。
