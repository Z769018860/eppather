 

\hypertarget{md_README_autotoc_md0}{}\doxysection{Psyche-\/C}\label{md_README_autotoc_md0}
Psyche is a rather unique compiler frontend for the C programming language that is specifically designed for the implementation of static analysis tools. This is where the \char`\"{}uniqueness\char`\"{} of Psyche-\/C comes from\+:


\begin{DoxyItemize}
\item Clean separation between the syntactic and semantic compiler phases.
\item Algorithmic and heuristic syntax disambiguation.
\item Type inference of missing {\ttfamily struct}, {\ttfamily union}, {\ttfamily enum}, and {\ttfamily typedef} ~\newline
 (i.\+e., tolerance and \char`\"{}recovery\char`\"{} against {\ttfamily \#include} failures).
\item A\+PI inspired by that of the \href{https://github.com/dotnet/roslyn}{\texttt{ Roslyn .N\+ET compiler}}.
\item A\+ST resembling that of the \href{https://clang.llvm.org/}{\texttt{ L\+L\+VM\textquotesingle{}s Clang frontend}}.
\end{DoxyItemize}\hypertarget{md_README_autotoc_md1}{}\doxysubsection{Library and A\+PI}\label{md_README_autotoc_md1}
Psyche-\/C is implemented as a library. Its native A\+PI is in C++ (A\+P\+Is for other languages are \href{https://github.com/ltcmelo/psychec/issues/112}{\texttt{ on the way}}).

These are a few application of type inference for C\+:


\begin{DoxyItemize}
\item Enabling, on incomplete source-\/code, static analysis techniques that require fully-\/typed programs.
\item Compiling partial code (e.\+g., a snippet retrieved from a bug tracker) for object-\/code inspection.
\item Generating test-\/input data for a function in isolation (without its dependencies).
\item Quick prototyping of an algorithm, without the need of explicit types.
\end{DoxyItemize}
